# Zoom Royal

Projet séparé — site d’enchères automobiles (style Barrett-Jackson).

Ce dossier **est** le projet. Rien à fusionner avec le GPS.

## Ouvrir

Double-clic sur `index.html`, ou :

```bash
python3 -m http.server 4173
```

Puis http://localhost:4173

## Contenu

- `index.html` — pages (accueil, lots, enchères, média, studio)
- `css/site.css` — présentation
- `js/catalog.js` — lots et vidéos (tu peux coller tes URLs ici)
- `js/app.js` — carrousel, fiches, lecteur vidéo, studio

## Ajouter une vidéo

Menu **Studio**, ou champ `video` dans `js/catalog.js` (YouTube, Vimeo, ou MP4).
