# L'Encan

Site web d’enchères automobiles (présentation type Barrett-Jackson).

**Projet séparé du GPS Zoom Royal.** On travaille ici uniquement sur le site.

## Ouvrir

```bash
python3 -m http.server 4173
```

http://localhost:4173

## Ajouter une vidéo

Menu **Studio**, ou le champ `video` dans `js/catalog.js` (YouTube, Vimeo, MP4).
