# Atelier

Outil privé, dans l’esprit Wix, pour créer des sites web d’entreprises.

Ce dossier est **indépendant du GPS**. Le GPS n’est pas modifié.

## Utilisation

1. Ouvre `index.html` (ou le lien en ligne).
2. Entre avec le mot de passe **`cursor`** (accès partagé avec Cursor).
   Lien direct : ajoute `?acces=cursor` à l’URL.
3. **Nouveau site client** → modèle, puis tu modifies.
4. **Partager avec Cursor** copie tes sites — colle-les dans le chat pour que j’y travaille.

Les sites sont enregistrés dans ce navigateur (localStorage).
