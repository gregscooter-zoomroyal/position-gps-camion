# Atelier

Outil privé, dans l’esprit Wix, pour créer des sites web d’entreprises.

Ce dossier est **indépendant du GPS**. Le GPS n’est pas modifié.

## Utilisation

1. Ouvre `index.html` (ou le lien en ligne).
2. Au premier lancement, choisis un mot de passe — l’atelier est verrouillé.
3. **Nouveau site client** → modèle (resto, métiers, salon, cabinet, commerce…).
4. Clique les textes pour les changer. Ajoute des blocs, une vidéo YouTube/Vimeo/MP4, des photos.
5. **Publier** donne un lien d’aperçu `#/p/nom-du-site`.

Les sites sont enregistrés dans ce navigateur (localStorage).
